# CustomRecipesAPI
This mod serves as an API mod to allow other mods to add custom recipes.  
This mod needs to be on both the Client and the Server in order for custom recipes to work properly, the same goes for any mods using this mod as a dependency.  

Specifically, it has systems that allow mods to add custom Moulds and SmeltingRecipes.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
